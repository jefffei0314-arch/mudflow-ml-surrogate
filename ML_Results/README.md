
# Machine Learning Results

This folder contains the validation and testing results generated by the main Python script, `CV7001_Assignment_3.py`.

## 1. Testing Results

- `model_performance_summary.csv`: R², RMSE and MAE for both models across the three held-out yield-stress cases (50, 500 and 2000 Pa).
- `comparison_yieldstress_*.csv`: Numerical simulation depths and corresponding machine learning predictions.
- `flow_profile_yieldstress_*.png`: Comparisons between numerical and predicted mudflow depth profiles at 180 s.
- `prediction_error_yieldstress_*.png`: Signed prediction errors for both machine learning models.

## 2. Validation Results

The `Validation/` subfolder contains:

- `validation_summary.csv`: Selected hyperparameters and cross-validation performance.
- `ridge_grid_search_test_*.csv`: Hyperparameter search results for Polynomial Ridge Regression.
- `random_forest_grid_search_test_*.csv`: Hyperparameter search results for Random Forest Regression.

The larger out-of-fold validation prediction files are not included in this repository but can be regenerated by running the main Python script.

## 3. Reproducing the Results

From the repository's main directory, run:

```bash
python CV7001_Assignment_3.py
```

The script performs model validation, training and testing, and saves the generated results in this folder.

For the full methodology, dataset description and inference instructions, refer to the main repository `README.md`.
